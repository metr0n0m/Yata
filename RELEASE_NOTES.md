# Yata — Release Notes

## 0.3.4 (2026-07-27)
- Номера строк слева от текста — точные абсолютные номера, ширина полосы подстраивается автоматически
- Статусбар внизу: «Ln N / M» — текущая строка и общее количество видимых строк
- Иконки вкладок (системная иконка файла)
- Исправлен фильтр: убран нестабильный асинхронный поток, сканирование синхронное и надёжное

## 0.3.3 (2026-07-27)
- Заголовок окна теперь показывает полный путь к файлу текущей вкладки без «- Yata»
- UNC-пути (\\server\share\...) отображаются как есть, без изменений

## 0.3.2 (2026-07-27)
- Фильтрация перенесена в отдельный поток — UI не блокируется при сканировании
  больших файлов, курсор меняется на часы во время поиска
- Инкрементальное сканирование при tail: новый контент сканируется в фоне без блокировки

## 0.3.1 (2026-07-27)
- Добавлено меню Filter (между View и Help)
- Filter → Filter by keyword — показывает только строки содержащие введённое слово или выражение
- Filter → Filter by pattern — показывает только строки совпадающие с одним из правил подсветки
- Filter → Clear filter — снимает фильтр, возвращает обычный просмотр
- В режиме follow-tail фильтр обновляется автоматически при дозаписи файла
- При ротации/усечении файла список совпадений пересканируется с нуля
- Статусбар показывает «Filter active: N matches» при активном фильтре
- Поиск при активном фильтре работает только по видимым (отфильтрованным) строкам

## 0.3.0 (2026-07-27)
- Исправлена подсветка: теперь работает постоянно, не сбрасывается при прокрутке
  и обновлении лога в режиме tail
- Подсветка встроена напрямую в цикл раскладки текста — гарантированно применяется
  при каждой перерисовке экрана
- При изменении правил подсветки экран обновляется автоматически без перезапуска

## 0.2.9 (2026-07-26)
- Исправлено: кнопки Edit и Delete теперь активируются при выборе правила
- Добавлен параметр Case sensitive для каждого правила (нечувствительность к регистру по умолчанию)
- Чекбокс включения/выключения правила теперь встроен в строку таблицы (колонка Pattern)
- Дубликаты правил с одинаковым паттерном и чувствительностью к регистру запрещены
- Превью в диалоге создания/редактирования правила показывает как подсветка будет выглядеть на текущей палитре из Preferences
- Превью в списке правил также использует текущую палитру Preferences

## 0.2.8 (2026-07-26)
- Добавлена подсветка ключевых слов и фраз (Edit → Highlighting...)
- Для каждого правила: паттерн, цвет текста и фона, опция regex, включить/выключить
- Правила сохраняются в ~/.yata/highlights.yaml
- Подсветка работает в реальном времени при слежении за логом (tail)
- Список правил с визуальным превью каждого правила

## 0.2.7 (2026-07-26)
- Упорядочены пути включения заголовочных файлов: каждый модуль теперь указывает
  полный путь к заголовкам других модулей (TODO автора с 0.2.0)
- Метод yFileCursor(QTextCursor) скрыт внутрь класса YTextDocument, добавлен
  чистый публичный метод fileCursorForLayoutLine() (TODO автора с 0.2.0)

## 0.2.6 (2026-07-26)
- Исправлен потенциальный сбой при поиске с пустой историей
- Исправлена потенциальная ошибка при чтении файла через memory-mapped I/O
- Исправлена логическая нестыковка скроллбара в режиме follow-tail при больших файлах
- Убран отладочный заголовок из кода (не влиял на работу)
- `QScopedPointer<bool>` для debug-menu заменён на два обычных поля

## 0.2.5 (2026-07-26)
- Файл настроек теперь содержит номер версии формата
- Если файл настроек создан более новой версией программы — показывается
  понятное сообщение, программа запускается с настройками по умолчанию

## 0.2.4 (2026-07-26)
- При повреждённом или нечитаемом файле настроек программа теперь показывает
  понятное сообщение об ошибке и запускается с настройками по умолчанию
  (раньше ошибка молча игнорировалась)

## 0.2.3 (2026-07-26)
- При повторном открытии файла программа теперь восстанавливает позицию прокрутки
  и состояние режима слежения за хвостом (follow-tail)
- Если файл был изменён, перезаписан, усечён или заменён — позиция не восстанавливается,
  файл открывается как новый (поведение предсказуемо при любом сценарии)
